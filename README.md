# Saloon Eysteins 🤠 – 50 ára

Lítill afmælisleikur fyrir Eystein, sem verður fimmtugur. Þrír smáleikir gegn versta sigurvegara Íslands:

- 🎱 **Pool:** settu fleiri kúlur ofan í en Eysteinn (hann fær stærri vasa, ekki spyrja)
- 🃏 **Póker:** fimm hendur af Texas Hold'em
- 👢 **Línudans-einvígi:** dansaðu í takt og sigraðu hann á dansgólfinu

Allur leikurinn er ein skrá, `index.html`. Opnaðu hana í vafra, eða spilaðu á GitHub Pages.
